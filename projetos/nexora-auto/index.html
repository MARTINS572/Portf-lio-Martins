    Como usar a demonstração

    1. Abrir uma ordem de serviço

      Use Nova OS, escolha o cliente e o veículo, informe a quilometragem e o que o cliente relatou. A ordem começa em Aguardando avaliação.

    2. Diagnóstico, itens e orçamento

      Na ordem, registre o diagnóstico, inclua serviços, peças e mão de obra e gere o orçamento. Colocar peça no orçamento não mexe no estoque.

    3. Aprovação e peças

      Registre como o cliente aprovou (é um registro interno, não uma assinatura digital). Na aprovação as peças ficam reservadas; se faltar, a ordem espera e a reserva acontece sozinha quando a peça entrar.

    4. Finalizar, faturar e receber

      Ao finalizar o serviço, as peças saem do estoque uma única vez. Encerrar a ordem fatura o valor, mas não marca como pago: o recebimento é registrado à parte. Nenhum pagamento é processado aqui.

    5. Perfis

      No menu do usuário (canto superior direito) dá para ver o sistema como recepcionista, técnico ou financeiro. É só uma simulação no navegador para mostrar as permissões; não é um login.

    Tudo é fictício e fica salvo só neste navegador. Esta versão não tem servidor nem login e não está pronta para uso real numa oficina. Para começar de novo, use Restaurar dados de exemplo no menu do usuário.
